Advanced Data Processor

The Advanced Data Processor runs abstract patterns: anything another machine makes, like smelting. Build it from three Processor Casings stacked in a column, then right-click the bottom one with the Assembly Wrench. Its network port is low on its back.

It holds up to nine abstract Pattern Floppies. Its top sends a recipe's inputs into the machine it faces, and its bottom takes the results back, from what it faces or from a hopper or pipe.

Only results returned through the processor count, and it only takes in what an order is waiting for. Items reaching storage another way, like a farm's importer, are never counted as an order's results.

The network needs a Crafting Computer to run orders. Without one, the processor will show 424.
