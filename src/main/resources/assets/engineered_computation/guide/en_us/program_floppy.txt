Program Floppy

A Program Floppy holds a filter of up to nine entries, each an item, a tag or a name, for example `c:ingots` for all ingots.

To program it, right-click while holding it, then click an entry while holding an item, or select an entry and type a tag. To filter by name, click the Tag button to switch it to Name first, names are matched against item IDs. Only supported in Floppy Disk Era Data Importers and Exporters.
