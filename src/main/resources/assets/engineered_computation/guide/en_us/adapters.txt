Data Adapters

A Data Importer pulls items from an inventory it faces, into the storage network it's connected to. A Data Exporter will pull items from the network into that inventory instead.

Adapters only connect to a Network Cable, on their back.

Importer's have a green light whilst exporter have Orange.

Right-click an adapter to open its settings. Its filter slot takes any item to filter by. With no filter, an importer imports everything and an exporter exports nothing. A status code provides information on what it's doing, see Error Codes in any guide book.

The button left of the filter slot switches the filter between an allow list and a block list, this works with a Program Floppy card as well.

Each era's adapters are faster. The transfer rate is configurable in their GUI.
