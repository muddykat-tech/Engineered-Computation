Pattern Floppy

A Pattern Floppy holds one recipe. Right-click while holding it to set the recipe, and click the button in its top corner to choose the type.

Direct: a crafting table recipe. Lay it out on the 3x3 grid and the result will fill in. Goes in a Crafting Computer.

Abstract: anything another machine makes, like smelting. Set the inputs and outputs with amounts (click for more, right-click for fewer). Goes in an Advanced Data Processor.

An abstract slot can hold a tag instead of an item: click an empty slot, type the tag and press Enter. An output tag accepts any of its items, for example forge:ingots/iron for any iron ingot. For an input tag, each order asks which item to send, so a tag like forge:raw_materials can smelt any ore. A pattern with a tag is ordered on its own from the terminal, never as part of another order. An input tag with more than eight items is marked "!".
